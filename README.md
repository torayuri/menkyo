# 学科◯×ドリル

普通免許の学科試験問題（970問）を◯×で解ける Web アプリです。

## できること

- **ランダム出題**：全問から 25 / 50 / 100 問をランダムに出題（未出題の問題を優先する設定あり）
- **項目別**：第1段階・第2段階の教習項目、仮免 A/B・本免の模擬テストを選んで出題（複数選択・シャッフル可）
- **苦手を復習**：直近で間違えた問題だけを出題
- **ブックマーク**：☆を付けた問題だけを出題
- 全問回答後（途中でも可）に**まとめて答え合わせ**。間違えた問題は解説を表示、間違えた問題だけの解き直しも可能
- **学習記録**：累計正答率、正答率の推移グラフ、学習カレンダー、項目別の成績、苦手な問題一覧、過去の挑戦の振り返り
- 途中で閉じても続きから再開可能。キーボード操作（`O` / `X` / `←` / `→`）対応、ダークモード対応

学習記録はブラウザの localStorage に保存されます。記録画面からバックアップ（JSON）の書き出し・読み込みができます。

## 開発

```sh
npm install
npm run dev      # 開発サーバー
npm run build    # dist/ に本番ビルド
```

### 問題データの更新

問題は `data/questions.xlsx`（列：段階 / 項目番号 / 問題番号 / 問題 / 回答 / 解説）が元データです。
Excel を差し替えたら次を実行して `src/data/questions.json` を再生成します（`openpyxl` が必要）。

```sh
npm run data
```

項目名は `scripts/xlsx_to_json.py` の `TITLES` で設定しています。
「図」「この標識」などを含む問題は図・標識が前提の問題として印が付き、設定で出題対象から外せます（画像は Excel に含まれていません）。

## 公開

`main`（または `claude/site-quiz-feature-g2h7nm`）ブランチに push すると GitHub Actions（`.github/workflows/deploy.yml`）で GitHub Pages にデプロイされます。
初回のみリポジトリの Settings → Pages → Source を「GitHub Actions」にしてください。
